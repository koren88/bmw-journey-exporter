# Security

Security fixes target the latest `main` branch. This project has no published
security-support version list.

For ordinary bugs, use a [public issue](https://github.com/koren88/bmw-journey-exporter/issues).
Do not include journey exports, raw phone XML, credentials, or other personal
data in public reports.

To report a suspected vulnerability privately, use [Report a vulnerability](https://github.com/koren88/bmw-journey-exporter/security/advisories/new). Do not disclose vulnerability details in a public issue.
